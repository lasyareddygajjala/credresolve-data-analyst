# Analysis plan
1. Inspect source inventory, status values, duplicates and conflicting references.
2. Reconcile account, borrower, agent and campaign IDs.
3. Validate timestamp zones before hour/day analysis.
4. Analyse recovery by DPD, risk, geography, channel, campaign, agent tenure and portfolio mix where columns support it.
5. Separate absolute collections, recovery rate, relative growth and percentage-point change.
6. Standardize portfolio mix to investigate Simpson's paradox.
7. For targeting change, define treatment/control and test pre-trends before difference-in-differences.
8. If cost data or causal identification is insufficient, recommend an experiment rather than invent ROI.
